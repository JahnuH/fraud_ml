Behavioural Anomaly Detection API
================================

Base URL
--------
https://aml.innovitegra.in/frms/behaviour

Authentication
--------------
- Public endpoint:
  - GET /frms/behaviour/health
- All other endpoints require HTTP Basic Authentication.
- Credentials are read from:
  - API_BASIC_AUTH_USERNAME
  - API_BASIC_AUTH_PASSWORD


1. Health Check
---------------

GET /frms/behaviour/health

10. Update Config Rules
-----------------------
Endpoint:
POST /frms/behaviour/config/rules/update

Sample Request:
{
  "rules": [
    {
      "behaviour_change_flag": false,
      "action_mapping": "ALLOW"
    },
    {
      "behaviour_change_flag": true,
      "action_mapping": "ALERT"
    }
  ]
}

Sample Response:
{
  "status": "ok",
  "updated_rules": [
    {
      "behaviour_change_flag": false,
      "action_mapping": "ALLOW"
    },
    {
      "behaviour_change_flag": true,
      "action_mapping": "ALERT"
    }
  ]
}


Notes
-----
- All protected endpoints accept JSON request bodies only.
- account_id, event_ts, and amount are mandatory only for POST /score-behaviour.
- Other contextual transaction fields are optional and may be sent as null.
- Missing categorical values are imputed server-side.
- If event_id is omitted in POST /score-behaviour, the backend generates one automatically.
